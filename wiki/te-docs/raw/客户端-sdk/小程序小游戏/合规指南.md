## 一. 隐私政策中填写 SDK 相关内容
### 1.1 收集和获取
在《隐私政策》中收集和获得您的个人信息栏目中根据实际情况填写以下内容。
当您在激活使用时，我们会通过TDAnalytics-SDK收集您的设备信息（设备型号，屏幕宽高，设备制造商，操作系统，操作系统版本，网络状态，系统语言等）用于统计分析您在应用内的使用效果。
### 1.2 与授权合作伙伴共享
在《隐私政策》中的与授权合作伙伴共享栏目中根据实际情况填写以下内容。
TDAnalytics-SDK：收集您的设备信息（设备型号，屏幕宽高，设备制造商，操作系统，操作系统版本，网络状态，系统语言等）用于数据分析，从而改进我们的产品和服务。
### 1.3 第三方信息共享清单
#### 腾讯广告小游戏SDK
**涉及个人信息：**手机型号、操作系统、分辨率、网络状态等设备基础信息，微信版本、小游戏打开场景值等应用环境信息等
**使用目的：**数据分析
**使用场景：**在数据上报的时候使用
**合作方主体：**深圳市腾讯计算机系统有限公司
**采集方式：**SDK自动采集
**官网链接：**https://datanexus.qq.com/doc/develop/guider/sdk/minigame/init
**合作方隐私政策：**https://datanexus.qq.com/doc/develop/compliance/minigame/privacy_policy
## 二. SDK合规步骤
ThinkingData SDK需要在用户同意 《隐私政策》后初始化
```javascript
// 根据隐私协议判断是否开启数据采集
if (授权隐私政策) {
    var config = {
        appId: "APP_ID", // 项目的 APP ID
        serverUrl: "SERVER_URL", // 数据上报地址
    }
    TDAnalytics.init(config);
}
```
