# 全量语义目录关键词与隔离召回对照

关键词已贯通既有 MySQL 列查询、全局/项目个人及项目公共目录、本地分页脚本。没有增加搜索、关键词匹配门槛、Top-N 或时间/数量过滤。已有条目保留原数据；本次改善新增和维护时的元数据指导。

## 结果

60 条虚构游戏语义、16 道问题，五组独立 agent 均命中全部 16 个必要候选，两道无匹配题也均未误选。本次没有观察到召回提升。原目录已有较好的标题和摘要，存在天花板效应；一次固定样本不能外推线上召回率。

| 组 | 目录内容 | 必要候选命中 | 目录 tokens | 相对原目录 | 目录+详情 tokens |
|---|---|---:|---:|---:|---:|
| A | 原标题摘要，无关键词 | 16/16 | 4,707 | — | 6,299 |
| B | 原标题摘要，加现有关键词 | 16/16 | 5,101 | +8.4% | 6,693 |
| C | 优化标题摘要，无关键词 | 16/16 | 4,616 | -1.9% | 6,210 |
| D | 优化标题摘要，普遍补词 | 16/16 | 6,107 | +29.7% | 7,701 |
| E | 优化标题摘要，选择性保留词 | 16/16 | 4,863 | +3.3% | 6,455 |

最终指导采用 E 的原则：允许空数组，保留有新增辨识价值的完整术语和已有来源别名，避免把标题摘要已经说明的内容再重复一遍。E 样例仅 12 条非空、合计 17 个词；其余 48 条为空。E 是观察开销后追加的探索性组，不作为预注册显著性检验。

tokens 使用 tiktoken 0.14.0 的 o200k_base 对实际分页脚本和详情脚本的完整序列化输出估算，不含等量问题、系统提示、回答或工具协议，不能当作实际平台计费 token 或 agent 总上下文用量。每个会话目录只初始化一次，此增量不是每题重复加载的成本。各组均读 16 个去重详情 ID；没有证据表明查询延迟或网络调用效率得到改善。

## 方法与限制

- 夹具包含 14 条既有完整语义和 46 条原目录活动干扰项；原标题、摘要、关键词和核心正文来自先前验收快照，没有故意劣化基线。46 条原条目本无关键词。
- 真值 gold 在优化字段前冻结；每臂一个 fork_turns=none 的独立 agent，只能读取本臂目录和同一套问题，禁止搜索、查看答案或其他臂。先读完整目录两页共 60 条，再固定全部候选，然后按 ID 读正文和必要依赖。
- A/C 使用修改前分页脚本，B/D/E 使用新脚本。关键词数组未丢失、未切分、未截断；其他消费指令相同。
- 构造器起初遗漏了真实 CLI 的 envelope、revision、expired，脚本在呈现目录前拒绝读取。统一补齐非语义字段并验证各臂均为两页 60 条后才开展评测。前置错误保留在日志，未计入正常数据成本或召回效果。
- E 在不读取问题、gold 或其他 agent 结果的前提下，仅依据正文、原关键词及优化后的标题摘要审查关键词冗余，逐词记录来源和理由。A-D、正文和 gold 未修改。
- 客观 ID 计分区分必要候选、允许的额外候选和依赖，不把所有额外候选都判错。没有另设独立 LLM Judge 评分，候选召回 100% 不代表完整回答正确率。

## 代表 case

- 新厨师头七天贡献价值：选七日 LTV 并读收入净额依赖，区分首次安装与注册、总额与人均。
- 买量七日回本：读 ROI 和收入依赖，核对渠道、成本、币种；缺成本时不报告数值。
- 资格到期但事件仍在：读父规则及资格依赖，发现正文有效期到 2026-08-31 与 expired=false 冲突，停止采用父规则并说明缺当前有效资格。
- 两道目录没有覆盖的问题：各组均返回无匹配，没有靠泛关键词凑条目。
