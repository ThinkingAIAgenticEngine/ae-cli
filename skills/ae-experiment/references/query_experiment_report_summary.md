# +query_experiment_report_summary

Query experiment report summary.

```bash
ae-cli experiment +query_experiment_report_summary --project_id <id> --exp_id <expId> [--force_refresh true]
```

Flags:
- `--project_id`, `-p`: Project ID.
- `--exp_id`: Experiment ID.
- `--force_refresh`: Optional boolean for report refresh.
