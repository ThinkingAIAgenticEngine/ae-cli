# Set up business tracking with an SDK

Use the host's picker for project selection, plan confirmation, code insertion approval, and setup completion. When the tracking Skill expects `ok`, offer **Confirm and continue** and **Request changes**; collect free text only for the requested changes or missing values.

1. Read `workspace_projects` and verify manifests and startup files. When the customer already selected a code directory, use it after verification. Otherwise show project choices with their platform and directory, and wait for a selection. Verify the AppID and receiver for the session's bound registration project with `ae-cli analysis project info get`, or use the `project.info.get` capability on the same host if the dedicated command is unavailable. Keep this AE target through the plan and code steps.
2. Load `ae-tracking-matrix` for routing. For a codebase without a plan, use `ae-generate-tracking-plan` with the selected codebase as source. For an existing plan, review a copy against the chosen entrypoints and reuse compatible events. Show the planned business events, properties and trigger locations for confirmation. If the selected SDK supports auto-collection, include its supported options in the plan review and let the user choose whether to enable them. Use the existing plan delivery flow for optional synchronization or Excel.
3. Hand the confirmed plan and resolved project context to `ae-generate-tracking-code`. Reuse existing initialization or add the supported SDK. Insert explicit tracking calls at the confirmed business triggers and apply the user's auto-collection choices. Preserve existing auto-collection settings unless the user confirms a change. Use one authoritative reporting location per business fact. Keep server credentials out of client code.
4. Run the project's normal non-deploying checks. Show the returned `realtime_data_url` and how to trigger the planned actions. In Chinese, label the link **查看实时数据**. Use the verified host and bound business project ID in `<host>/#/data/realtime?setupProjectId=<project_id>` if an older CLI omits the URL. Present **I finished setup** and **I need help testing** in a picker. After confirmation, resume `run --choice business --sdk-complete` and include the link again. Report event arrival only after observing the customer's events in AE.
