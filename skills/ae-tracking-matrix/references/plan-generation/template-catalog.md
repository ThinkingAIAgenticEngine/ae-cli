# Industry Template Index

> These template files are not part of the Agent Skills standard directory, but are defined in this skill as internal experience assets.
> Usage order: first read this page to pick a template, then open `../categories/*.md` as needed, and finally return to `../naming-dict.md` for unified normalization.

## Usage Principles

1. Open only the closest 1 to 2 templates; do not read all assets at once.
2. Templates are used to supplement modules, common properties, and event families; they do not directly decide the final field names and types.
3. If a template conflicts with `../naming-dict.md` or `reference.md`, the latter two take precedence.
4. When a game category is unclear, first combine with `module-baseline.md`, then pick a sub-category template.

## Selection Suggestions

- Short drama and IAA content products: prefer `../categories/short_drama_tracking_plan_template.md`.
- Mid/hardcore RPG, card, idle, Roguelike: start from the corresponding game template, then supplement the base from `module-baseline.md`.
- SLG, MMO, simulation/management: prefer the category template, then confirm whether to add heavy-system modules such as alliance, guild, construction, resources, and trading.
- Social and e-commerce: prefer the corresponding business template and avoid directly applying game fields.
- Blockchain games: prefer `../categories/blockchain_game_tracking_plan_template.md`; note the binding between wallet accounts and role IDs.
- Online education: prefer `../categories/online_education_tracking_plan_template.md`; the core chain is course discovery -> enrollment -> learning -> quiz -> completion.
- Tools (editing/video, etc.): prefer `../categories/video_editor_tracking_plan_template.md`; focus on the creation flow and the export conversion funnel.
- Reading / content subscription: prefer `../categories/reading_tracking_plan_template.md`; focus on deep book reading and payment/subscription conversion.
- Idle Card: the local cache lacks an event list; compose confirmed modules from Idle + Card, and do not invent a standalone complete Idle Card template.
