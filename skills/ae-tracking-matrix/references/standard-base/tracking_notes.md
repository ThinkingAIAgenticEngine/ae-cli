| Q1 | Tracking Data Types | See "Data Type Design Principles" for details;<br>1. Event names / property names: String type; may begin with a digit or letter, may contain digits, letters, and underscores "\_"; max length 50 characters; case-insensitive for letters; only preset properties may begin with "#".<br><br>2. The type of a property field is determined by the type at the time of its first ingestion; when the ingested type is wrong:<br>Option 1: Use the secondary development tool to forcibly change the type, but the field values of already-ingested data will be set to null (usable during the early data testing phase)<br>Option 2: Use type virtual properties to convert the type; subsequent analysis simply uses the corresponding virtual property<br>Option 3: Keep the original field, use a new field to report data with the correct type, and later use virtual properties for joint deduplication<br><br>3. For number-type fields, pay attention to value limits. For fields that do not need numeric operations, we recommend using string type. | Modify data type: https://docs.thinkingdata.cn/ta-manual/latest/technical_document/ta_tool/modify_meta.html |
