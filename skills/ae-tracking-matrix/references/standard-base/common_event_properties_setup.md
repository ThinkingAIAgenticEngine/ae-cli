If `setSuperProperties:` is called to set a common event property that was previously set, it will overwrite the previous property. If a common event property has the same key as a property uploaded via `track:properties:`, the event's property will override the common event property.<br><br>Note: After the user logs out, in addition to calling the logout method, you may also need to clear the currently set common event properties that have an account dependency.
