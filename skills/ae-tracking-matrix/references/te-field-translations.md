## III. Translation Inference Rules

- Contains `amount` → Amount/Quantity; contains `num`/`count` → Count; contains `id` → ID; contains `time` → Time; contains `reason` → Reason
- Contains `is_`/`has_` prefix → Boolean (whether/presence); contains `first`/`last` → First/Last
- Prefix `tmp_` → transient state (snapshot value); prefix `first_` → first attribution/first behavior
- Field names that cannot be inferred keep their original English names, to be supplemented manually
