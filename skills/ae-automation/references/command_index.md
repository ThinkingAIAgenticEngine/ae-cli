# Automation commands

| Command                         | Purpose              | Risk            |
| ------------------------------- | -------------------- | --------------- |
| `ae-cli automation list`        | Automation lifecycle | read            |
| `ae-cli automation get`         | Automation lifecycle | read            |
| `ae-cli automation create`      | Automation lifecycle | write           |
| `ae-cli automation update`      | Automation lifecycle | write           |
| `ae-cli automation enable`      | Automation lifecycle | write           |
| `ae-cli automation disable`     | Automation lifecycle | write           |
| `ae-cli automation delete`      | Automation lifecycle | high-risk-write |
| `ae-cli automation run`         | Automation lifecycle | write           |
| `ae-cli automation runs list`   | Automation lifecycle | read            |
| `ae-cli automation runs get`    | Automation lifecycle | read            |
| `ae-cli automation runs stop`   | Automation lifecycle | high-risk-write |
| `ae-cli automation runs retry`  | Automation lifecycle | write           |
| `ae-cli automation runs result` | Automation lifecycle | read            |
