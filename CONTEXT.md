# Analysis client evaluation context

An arm is a paired CLI and complete Skills from one frozen commit. A formal attempt is one initial model session plus any required resumes; failed attempts remain samples. A probe validates runtime readiness and never counts as an analysis sample. A contract cache is local per-attempt state, distinct from shared backend query caching. A completed process does not establish answer quality.
