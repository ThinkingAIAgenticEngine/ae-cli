# 棋牌类（斗地主）埋点模板_v1

## 事件数据

| 事件名 | 显示名 | 说明 | 标签 | 平台 | 属性 |
| --- | --- | --- | --- | --- | --- |
| authorize | 用户授权 | 授权完成后 |  |  |  |
| ta_mp_show | 游戏启动 | 在游戏启动时触发（客户端开启自动采集后，即可采集） |  |  |  |
| login | 游戏登录 | 用户进入游戏页面时记录 |  |  | login_enter |
| ta_mp_hide | 游戏登出 | 游戏登出时记录（客户端开启自动采集后，即可采集） |  |  | #duration |
| level_up | 段位升级 | 段位升级时调用 |  |  | new_level |
| game_start | 游戏开始 | 进入每局游戏时记录，并开始计时 |  |  | round_id, first_mode, second_mode, role_name |
| game_result | 游戏结束 | 每局游戏结束时记录，并结束计时 |  |  | round_id, first_mode, second_mode, role_name, #duration, is_win, bean_change |
| go_bomb | 出炸弹 | 在一局游戏中出炸弹时记录 |  |  | round_id |
| go_times | 加倍 | 在一局游戏中点击加倍后记录 |  |  | after_times, round_id |
| open_deal | 明牌 | 在某一局游戏中明牌时记录 |  |  | round_id |
| go_broke | 破产 | 某一局结束后破产时记录 |  |  | round_id |
| order_paid | 订单支付 | 用户完成付款后触发 |  |  | order_id, pay_amount, pay_enter, pay_reason, pay_type, is_first_pay |
| resource_exc | 资源兑换 | 资源兑换时触发，基本入口有”红包”，”兑换”，”商城” |  |  | exc_entrance, get_resource, get_num, cost_resource, cost_num |
| resource_change | 资源变动 | 资源或道具发生变动时触发，
（钻石/红包/趣味豆/记牌器/超级加倍卡/福卡） |  |  | resource_name, change_type, change_num, change_before, change_after, change_reason |
| ad_show | 广告展示 | 广告展示时触发，比如游戏结束时的广告展示 |  |  | ad_id, ad_location |
| ad_start | 广告开始 | 广告开始播放，并启动计时器开始计时 |  |  | ad_id, ad_location, ad_time |
| ad_end | 广告结束 | 广告停止播放，并结束计时器 |  |  | ad_id, ad_location, ad_time, ad_duration, view_complete |
| click_share | 点击分享按钮 | 点击分享按钮或者发送给好友，但未分享 |  |  | share_location |
| share | 分享 | 真实完成分享后触发 |  |  | share_location |
| rank_list | 排行榜 | 服务器每天固定时间（比如每天0点）上传，每个排行榜上的用户，对应上传一条排行榜事件 |  |  | rank_type, rank_no |
| sign | 完成签到 | 签到领取时记录 |  |  | get_mode, resource_name, num, is_video_sign, sign_day |
| daily_gift | 每日礼包 | 完成领取时触发 |  |  | resource_list, num_list, reward_name |
| lucky_wheel | 幸运转盘 | 真实触发一次转盘时记录 |  |  | resource_name, num |
| task_completed | 完成任务 | 点击领取时记录 |  |  | task_ID, task_name, resource_name, num |
| get_mail_reward | 领取邮件奖励 | 邮件模块，点击领取奖励时记录 |  |  | resource_name, num, reward_name |
| more_welfare | 更多福利 | 更多福利模块，领取奖励时记录 |  |  | resource_name, num, reward_name |
| tap_addapp | 点击添加到小程序 | 点击添加到我的小程序时记录 |  |  | button_id |
| tap_otherapp | 点击其他游戏 | 点击其他游戏icon时记录 |  |  | button_id, other_appid, other_appname |
| tap_fast_start | 点击快速开始 | 点击快速开始按钮时记录 |  |  |  |

## 公共事件属性

| 属性名 | 显示名 | 类型 | 说明 |
| --- | --- | --- | --- |
| season | 当前赛季 | string | 当前赛季，比如S11 |
| level | 当前段位 | string | 用户当前段位，比如青铜2 |
