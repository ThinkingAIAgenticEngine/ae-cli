## 公共事件属性

| 属性名 | 显示名 | 类型 | 说明 |
| --- | --- | --- | --- |
| user_register_time | 注册时间 | datetime | 注册时间，未获取到传当前时间 |
| app_user_first_open_timestamp | 首次启动时间 | datetime | 用户当前版本首次打开应用的时间 |
| is_overlap_user | 是否重复用户 | bool | 首次登录时间比注册时间晚1天以上，定为重复用户传true，否则传false |
| media_source | 媒体渠道 | string | 归因平台，未获取时传空，根据归因结果传中台的srcplat，如果非推广来源用户传organic |
| first_cpm | 首次cpm | number | 用户首次激励视频的eCPM值，单位分,没取到时传-1 |
| tag1 | 用户价值 | string | 用户价值分组，传对应的tag，详见用户分组需求 |
| is_adb_enabled | 是否开启adb | bool | 是否开启adb |
| is_vpn_enabled | 是否开启vpn | bool | 是否开启vpn |
| active_days | 活跃天数 | number | 用户处于第几个自然天,事件时间-注册时间，跨天允许有误差，异常传-1 |
| version_active_days | 当前版本活跃天数 | number | 当前版本用户处于第几个自然日，事件时间-app_user_first_open_timestamp |
