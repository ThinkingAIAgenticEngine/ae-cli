## 公共事件属性

| 属性名 | 显示名 | 类型 | 说明 |
| --- | --- | --- | --- |
| vip_type | VIP属性 | number | 事件发生时玩家的是否是VIP，0:否 ； 1:是 |
| user_login_type | 登录模式 | string | 1:fb; 2:imo; 0:游客 |
| is_first_day | 是否首日 | bool | 1:代表玩家是注册首日的标识；0:代表玩家已经离注册超过了24小时； |
| channel | 版本渠道 | string | gp:代表GooglePlay商店；oppo:代表OPPO官方商店；offical:代表官方渠道 |
| channel_code | 子渠道代码 | string | 例如offical官方渠道，对于一些特定KOL群主的下发包的来源，对应填写的编码。其他channel默认为0 |
| area | 地区信息 | string | 看第三方支付能否返回的地区信息，拉取定位信息相关（优先级低，有数数的IP定位的地址即够用） |
